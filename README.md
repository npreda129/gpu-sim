Dependencies:
This project requires c11. The only non-standard library used is SDL2: https://wiki.libsdl.org/SDL2/Installation

Build:
`make` will build all the executables in the build/ folder. You can optionally specify one of the targets `mandelbrot` and `retriever`

Run Demos:
- `mandelbrot` takes no arguments, simply run it from the command line
- `retriever` takes one argument, the name of the .obj file to be visualized
